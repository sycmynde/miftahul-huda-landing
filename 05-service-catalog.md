# KATALOG LAYANAN & HARGA — Miftahul Huda

## Tier 1 — Starter (UMKM / kantor kecil / sekolah kecil)
**Target:** 1-10 user, 1 lokasi
- Servis PC/laptop (diagnosis + perbaikan)
- Setup router MikroTik + Wi-Fi dasar
- Backup data ke external drive / cloud sederhana
- Remote support via WhatsApp/Tailscale
**Harga:** Rp 300rb-800rb sekali / Rp 300rb-500rb per bulan (maintenance)

## Tier 2 — Business (kantor menengah / sekolah)
**Target:** 10-50 user, 1-2 lokasi
- Server lokal (Windows/Linux) + file sharing
- NAS + backup otomatis + user permissions
- Jaringan LAN + MikroTik (VLAN, hotspot, bandwidth mgmt)
- Monitoring dasar + backup off-site (Tailscale)
- Maintenance bulanan + remote support
**Harga:** Rp 3-8jt setup sekali / Rp 800rb-2jt per bulan (maintenance)

## Tier 3 — AI Lokal / On-Premise (toko, bengkel, kantor)
**Target:** bisnis yang mau AI tapi data tetap di tempat
- AI assistant/chatbot lokal (Ollama + GGUF) untuk toko/bengkel/kantor
- Multi-model router (chat + image gen + voice) opsional
- Integrasi alur pesanan / verifikasi bukti (human-in-the-loop)
- Deployment on-premise, GPU optimization, 24/7 operation
- Dokumentasi + training admin + 30 hari support
**Harga:** Rp 5-15jt setup sekali / Rp 1-3jt per bulan (maintenance + update model)

## Add-on (opsional, semua tier)
- Konsultasi on-site: Rp 500rb-1.5jt/hari
- Migrasi data (server lama → baru): Rp 1-3jt
- Training staf IT (2 jam): Rp 500rb-1jt
- Audit jaringan & keamanan: Rp 1-2jt

## Catatan pricing
- Harga di atas adalah range; sesuaikan dengan scope & kompleksitas.
- Untuk klien lama / referral: diskon 10-15%.
- Untuk proyek besar (>Rp 20jt): bagi termin (30% DP, 40% progress, 30% serah terima).
- Jangan diskon terlalu dalam — jaga nilai. Lebih baik tambah value (support lebih lama) daripada potong harga.
